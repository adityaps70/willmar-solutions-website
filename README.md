# Willmar Solutions — website

Static site for Willmar Solutions Pte. Ltd. (Singapore marine consultancy). Twelve self-contained HTML pages, images in `img/`, hosted on GitHub Pages.

- `index.html` — home; one file per page alongside it
- `img/` — photography, team portraits, logo assets
- Enquiry form hands off to services@willmarsolutions.com via the visitor's email app; swap in a form service for server-side delivery.
